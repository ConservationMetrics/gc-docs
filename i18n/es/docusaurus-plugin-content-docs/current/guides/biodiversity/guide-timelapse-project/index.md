# Timelapse: Configuración de un Proyecto para Anotación de Trampas de Cámara

## Introduction

[Timelapse](https://timelapse.ucalgary.ca/) es un **software para sistema operativo Windows para revisar datos de trampas de cámara y transformar archivos de imagen y video sin procesar en datos estructurados** que pueden proporcionar información sobre la presencia, diversidad y tendencias poblacionales de especies. Esta es una introducción rápida al uso del software.

![Timelapse Software screenshot](/img/guides/guide-timelapse-project/timelapse.jpg)

:::note
Timelapse está en desarrollo activo, es de código abierto ([repositorio de GitHub](https://github.com/saulgreenberg/Timelapse)) y cuenta con documentación completa. Para obtener información detallada, consulte los siguientes recursos.
:::

:::tip
Esta guía es solo para **anotar** imágenes y videos de trampas de cámara que ya han sido recopilados. No es una guía para configurar un proyecto de trampa de cámara o para manejar la implementación.

Para la implementación, consulta la guía [Implementación de trampas de cámara](/guides/biodiversity/guide-camera-trap-deployment/).
:::

## Instalación de Timelapse

Timelapse se puede descargar [aquí](https://timelapse.ucalgary.ca/download/). Existen tres métodos de instalación diferentes. Recomendamos usar el "1 MSI Per-User Installer (recomendado para la mayoría)" a menos que haya alguna razón por la que necesite usar uno de los otros métodos de instalación.

- :bar_chart: [Conjunto de imágenes de práctica de Timelapse](https://timelapse.ucalgary.ca/wp-content/uploads/Guides/PracticeImageSet.zip)  
  Esto es realmente útil como plantilla para construir tu propio proyecto Timelapse.

- :open_book: [Guías de Usuario y Tutoriales](https://timelapse.ucalgary.ca/guides/)
  - **[Guía de Inicio Rápido (PDF)](https://timelapse.ucalgary.ca/wp-content/uploads/Guides/TimelapseQuickStartGuide.pdf)**  
    Una guía práctica que te acompaña en la carga, inspección y etiquetado de un conjunto de imágenes y videos de práctica.

  - **[Guía de Referencia (PDF)](https://saul.cpsc.ucalgary.ca/timelapse/uploads/Guides/TimelapseReferenceGuide.pdf)**  
    Cubre todas las características disponibles en detalle. Muy recomendado para optimizar tu flujo de trabajo.

  - **[Guía de Plantillas (PDF)](https://timelapse.ucalgary.ca/wp-content/uploads/Guides/TimelapseReferenceGuide.pdf)**  
    Explica cómo crear y gestionar plantillas usando el Editor de Plantillas de Timelapse.

  - **[Guía de Metadatos (PDF)](https://timelapse.ucalgary.ca/wp-content/uploads/Guides/TimelapseImageRecognitionGuide.pdf)**  
    Esta guía explica cómo asociar metadatos a nivel de carpeta con tu conjunto de imágenes y cómo rellenarlos. También incluye varios estándares de metadatos.

  - **[Guía de Reconocimiento de Imágenes (PDF)](https://timelapse.ucalgary.ca/wp-content/uploads/Guides/TimelapseImageRecognitionGuide.pdf)**  
    Esta guía explica cómo usar la función de reconocimiento automático de imágenes en Timelapse.

  - **[Guía de Base de Datos (PDF)](https://timelapse.ucalgary.ca/wp-content/uploads/Guides/TimelapseDatabaseGuide.pdf)**  
    Detalla la estructura interna de la base de datos. Útil si planeas acceder directamente a la base de datos.
