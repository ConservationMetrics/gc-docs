# Documentación de Guardian Connector

¡Bienvenido al centro de documentación de Guardian Connector! Este recurso exhaustivo proporciona orientación para comprender y utilizar Guardian Connector para apoyar las necesidades de tutela, soberanía de datos y monitoreo ambiental de las organizaciones comunitarias.

_Content last revised: <LastRevisedDate />_
:::

## Qué cubre esta documentación

Esta documentación proporciona una guía completa para:

### 🏗️ **[Descripción general](./overview/)**
Las ideas detrás de la plataforma: principios de diseño, para quién es, si Guardian Connector se adapta a una organización y respuestas a preguntas comunes.

### 📚 **[Referencia](./reference/)**
Cómo funcionan las partes de la plataforma y cómo se relacionan entre sí: el conjunto de herramientas, las integraciones, las aplicaciones complementarias y los flujos de trabajo para ingresar, monitorear, compartir y extraer datos.

### 🎓 **[Guías](./guides/)**
Tutoriales paso a paso para herramientas y prácticas utilizadas junto con Guardian Connector, desde la recopilación de datos móviles y el monitoreo de la biodiversidad hasta el monitoreo de la tierra y la soberanía de datos indígena.

## Personas de usuario

No todos usan todas las capas de Guardian Connector. Diferentes [personas de usuario](./overview/user-personas/) suelen operar diferentes partes del stack. Por ejemplo:

- Un [Usuario de Tecnología Indígena](./overview/user-personas/#itu-1) de cualquier nivel de experiencia puede usar solo las aplicaciones de recopilación de datos que alimentan Guardian Connector.
- Un [Usuario de Tecnología Indígena avanzado](./overview/user-personas/#itu-3) también puede manejar alguna configuración básica de vistas o paneles.
- Un [Tomador de Decisiones Indígena](./overview/user-personas/#idm) puede acceder solo a paneles y vistas de datos, y no necesitará saber mucho más sobre los detalles técnicos del sistema.
- Un [Usuario Avanzado Organizacional](./overview/user-personas/#opu) puede administrar todo el stack, a veces con el apoyo de un [Socio de Soporte Técnico](./overview/user-personas/#tsp), y en otros casos completamente por su cuenta.
