This month has come with a plethora of updates in multiple fronts. Let's dive straight into them.

<!-- truncate -->

## **GC Landing Page**

* **Guided Tour:** Added a new, responsive, internationalized guided tour using coach marks to orient new users (stored in local browser storage).

![coachmarks](/img/whatsnew/coachmarks.png)

* **Custom Apps:** New feature allows administrators to display custom cards for additional applications on the landing page.

![custom apps](/img/whatsnew/custom-apps.png)

* **User Identification:** Restored the username to the header to assist users in shared-computer environments.

![email](/img/whatsnew/email.png)

## **GC Scripts Hub**

* **New Connectors:** Added support for [iNaturalist](https://www.inaturalist.org/) and [Sensing Clues](https://www.sensingclues.org/).
* **Mapbox Script:** Added a script to [download and reconstruct vector tiles from Mapbox](https://github.com/ConservationMetrics/gc-scripts-hub/tree/main/f/connectors/mapbox#mapbox_download_vector_tiles-download-vector-tiles-to-geojson).
* **Code Improvements:** Improved handling of non-Latin characters in data set names and properties.
* **KoboToolbox Webhooks:** [Documented](https://github.com/ConservationMetrics/gc-scripts-hub/blob/main/f/connectors/kobotoolbox/README.md#webhooks) process for instant data retrieval via REST API.
* **Data Set Uploader:** Added a loading indicator to provide visual feedback during database record checks.

![loader](/img/whatsnew/loader.png)

## **GC Explorer**

* **Gallery Overhaul:** Redesigned as media-first; includes carousel experience, property displays, mini-maps for coordinate fields, and direct file download links.

![gallery overhaul](/img/whatsnew/gallery-overhaul.png)

* **Config UI:** Overhauled interface with dropdowns instead of text inputs and added in-app documentation/tooltips.
* **Alerts Dashboard:** Moved alert date range selector to a more prominent position; grouped download buttons; restored "blinking" dots feature.
* **Visuals:** Login page background now synchronizes with landing page branding settings.

## **GC Wildlife Viewer**

* **Map Improvements:** Mini-map updated to use satellite imagery; interface is now resizable.

![wildlife viewer](/img/whatsnew/wildlife-viewer.png)

## **GC Docs**

* **Massive Copy Overhaul:** Rewrote documentation to align with the current project mental model.
* **User Personas:** Renamed "Tags" to "User Personas" and moved section to the top of the page.
* **New Content:** Added guides for camera trap deployment, Landing Page configuration, Superset role syncing, and `__labels` table usage.

This month has been really intense with a lot of updates. The article doesn't make justice to the sheer amount of changes that have been deployed, and we hope you get to know them through the documentation.
