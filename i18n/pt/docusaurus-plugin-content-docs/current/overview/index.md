# Sobre o Guardian Connector

_Guardian Connector é uma plataforma de integração e monitoramento de dados segura e de código aberto._

Posiciona os Povos Indígenas para coletar, gerenciar e possuir dados sobre seus territórios em seus próprios termos. Simplifica o caminho da coleta de dados à ação, ajudando os usuários a criar ferramentas de defesa poderosas que apoiam a guarda de suas terras e águas.

:::tip Visite o site do Guardian Connector
:link: Para uma introdução geral à plataforma, visite o [site do Guardian Connector](https://guardianconnector.net).
:::
