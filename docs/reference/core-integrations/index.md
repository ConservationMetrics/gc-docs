# Core Integrations

Guardian Connector is designed to work closely with a small number of external applications that are commonly used within Indigenous community monitoring and data management workflows. These integrations allow data collected or processed in other tools to be brought into Guardian Connector for storage, management, analysis, visualization, and longer-term use.

:::important
These three applications do **not** represent the full range of systems that Guardian Connector can work with. Through [GC Scripts Hub](/reference/gc-toolkit/gc-scripts-hub/), Guardian Connector can connect to many more APIs, databases, file exports, and other external platforms, including systems such as ODK, ArcGIS Online, Global Forest Watch, and other sources used by partner organizations.

These connections are configured according to the needs of a particular organization or workflow and are therefore documented within GC Scripts Hub rather than treated as core integrations.

Guardian Connector is intended to complement the tools organizations already use rather than require a single standardized data collection system. New integrations can be added as organizational needs and workflows evolve.
:::

## Core Integrated Applications

### [KoboToolbox](/reference/core-integrations/kobotoolbox/)

Mobile data collection and survey management, including structured forms and field-based monitoring workflows.

### [CoMapeo](/reference/core-integrations/comapeo/)

Offline-first mapping and data collection for communities, including georeferencing and photo/audio/video attachment support.

### [Timelapse](/reference/core-integrations/timelapse/)

Camera trap image analysis and wildlife monitoring, including image tagging and species identification.

These applications are documented here because Guardian Connector has established workflows for working with their data and because they are used extensively by current partner organizations. For these tools, we also provide additional resources such as templates, recommended configurations, best practices, and guidance for common workflows.
