# Timelapse: Configurando um Projeto para Anotação de Armadilhas Fotográficas

## Introduction

[Timelapse](https://timelapse.ucalgary.ca/) é um **software para Windows OS para revisar dados de armadilhas fotográficas e transformar arquivos brutos de imagem e vídeo em dados estruturados** que podem fornecer insights sobre a presença de espécies, diversidade e tendências populacionais. Esta é uma introdução rápida ao uso do software.

![Timelapse Software screenshot](/img/guides/guide-timelapse-project/timelapse.jpg)

:::note
O Timelapse está sendo ativamente desenvolvido, é de código aberto ([repositório GitHub](https://github.com/saulgreenberg/Timelapse)) e possui documentação abrangente. Para informações detalhadas, consulte os seguintes recursos.
:::

:::tip
Este guia é apenas para **anotar** imagens e vídeos de armadilhas fotográficas que já foram coletados. Não é um guia para configurar um projeto de armadilha fotográfica ou gerenciar a implantação.

Para implantação, consulte o guia [Implantação de Armadilhas Fotográficas](/guides/biodiversity/guide-camera-trap-deployment/).
:::

## Instalando o Timelapse

O Timelapse pode ser baixado [aqui](https://timelapse.ucalgary.ca/download/). Existem três métodos de instalação diferentes. Recomendamos usar o "1 MSI Per-User Installer (recomendado para a maioria)", a menos que haja alguma razão pela qual você precise usar um dos outros métodos de instalação.

  - **[Guia de Referência (PDF)](https://saul.cpsc.ucalgary.ca/timelapse/uploads/Guides/TimelapseReferenceGuide.pdf)**  
    Abrange todos os recursos disponíveis em detalhes. Altamente recomendado para otimizar seu fluxo de trabalho.
