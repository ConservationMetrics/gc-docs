# Documentação do Guardian Connector

Bem-vindo ao centro de documentação do Guardian Connector! Este recurso abrangente fornece orientação para compreender, implantar e usar o Guardian Connector para apoiar as necessidades de soberania de dados e monitoramento ambiental de organizações comunitárias.

:::info Latest update
_Content last revised: <LastRevisedDate />_
:::

## O Que Esta Documentação Abrange

Esta documentação fornece orientação abrangente para:

### 🏗️ **[Visão Geral](./overview/)**
Compreender o propósito do Guardian Connector, como ele funciona, princípios de design e como ele se encaixa no trabalho mais amplo de monitoramento e advocacia de organizações comunitárias.

### 📚 **[Referência](./reference/)**
Informações de referência detalhadas sobre ferramentas integradas, opções de hospedagem e especificações técnicas para ajudar as organizações comunitárias a tomar decisões informadas sobre a implementação.

### 🎓 **[Guias](./guides/)**
Guias abrangentes para estabelecer práticas de dados centradas na comunidade, incluindo protocolos de soberania de dados Indígenas e fluxos de trabalho específicos de ferramentas.

## Personas de Usuário

Nem todos usam todas as camadas do Guardian Connector. Diferentes [personas de usuário](./overview/user-personas/) geralmente operam diferentes partes da pilha. Por exemplo:

- Um [Usuário de Tecnologia Indígena](./overview/user-personas/#itu-1) de qualquer nível de experiência pode usar apenas os aplicativos de coleta de dados que alimentam o Guardian Connector.
- Um [Usuário de Tecnologia Indígena avançado](./overview/user-personas/#itu-3) também pode lidar com alguma configuração básica de visualizações ou painéis.
- Um [Tomador de Decisões Indígena](./overview/user-personas/#idm) pode apenas acessar painéis e visualizações de dados, e não precisará saber muito mais sobre os detalhes técnicos do sistema.
- Um [Usuário Avançado Organizacional](./overview/user-personas/#opu) pode administrar toda a pilha, às vezes com o apoio de um [Parceiro de Suporte Técnico](./overview/user-personas/#tsp), e em outros casos inteiramente por conta própria.

:::tip Personas de Usuário em toda a documentação
Usamos tags de Personas de Usuário para direcioná-lo a conteúdo escrito para uma determinada função e nível de experiência. Procure por tags de persona no topo de cada página — elas mostram para quem é a página, e você pode clicar em uma tag para ver mais páginas marcadas para aquele público.
:::
