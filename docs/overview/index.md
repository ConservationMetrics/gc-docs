# About Guardian Connector

_Guardian Connector is an open-source secure data integration and monitoring platform._

It positions Indigenous Peoples to collect, manage and own data about their territories on their terms. It streamlines the path of data collection to action, helping users create powerful advocacy tools that support guardianship of their lands and waters.

:::tip Visit the Guardian Connector website
:link: For a general introduction to the platform, visit the [Guardian Connector website](https://guardianconnector.net).
:::

This Overview section of the documentation goes further into the ideas behind the platform: the principles that shape it, who it is designed for, and how to decide whether it fits an organization.
