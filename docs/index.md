# Guardian Connector Documentation

Welcome to the Guardian Connector documentation hub! This comprehensive resource provides guidance for understanding, deploying, and using Guardian Connector to support community organizations’ data sovereignty and environmental monitoring needs.

:::info Latest update
_Content last revised: August 17, 2026_
:::

## What This Documentation Covers

This documentation provides comprehensive guidance for:

### 🏗️ **[Overview](./overview/)**
Understanding Guardian Connector's purpose, design principles, and how it fits into community organizations' broader monitoring and advocacy work.

### 📚 **[Reference](./reference/)**
Detailed reference information about integrated tools, hosting options, and technical specifications to help community organizations make informed decisions about implementation.

### 🎓 **[Guides](./guides/)**
Comprehensive guides for establishing community-centered data practices, including Indigenous data sovereignty protocols and tool-specific workflows.

## Who This Documentation Is For

This documentation is designed for:

- **Technical Coordinators** implementing, configuring, and maintaining Guardian Connector 
- **Data Managers** organizing and analyzing community information on Guardian Connector
- **Community Leaders** using data and reports to make informed decisions about their community and environment
- **Field Researchers** collecting environmental and cultural data together with community organizations
- **Advocates** using data for conservation and rights-based campaigns
