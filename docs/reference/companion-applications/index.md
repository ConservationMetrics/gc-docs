# Companion Applications

Documentation for external applications that are useful alongside Guardian Connector but are not themselves part of the Guardian Connector platform or directly integrated into it.

**What you'll find:**
- Tools such as [QGIS](/reference/companion-applications/qgis/) for working with spatial data
- Tools such as [OpenRefine](/reference/companion-applications/openrefine/) for cleaning and restructuring data
Recommendations for applications that complement Guardian Connector workflows before, after, or outside the platform

**Best for:** Finding tools for specialized tasks such as data cleaning, analysis, mapping, and working with data exported from Guardian Connector.
