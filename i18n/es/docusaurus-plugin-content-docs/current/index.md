# Documentación de Guardian Connector

¡Bienvenido al centro de documentación de Guardian Connector! Este recurso integral proporciona orientación para comprender, desplegar y utilizar Guardian Connector para apoyar las necesidades de soberanía de datos y monitoreo ambiental de las organizaciones comunitarias.

_Content last revised: <LastRevisedDate />_

## Qué cubre esta documentación

Esta documentación proporciona orientación completa para:

### 🏗️ **[Visión general](./overview/)**
Comprender el propósito de Guardian Connector, cómo funciona, sus principios de diseño y cómo encaja en el trabajo más amplio de monitoreo y defensa de las organizaciones comunitarias.

### 📚 **[Referencia](./reference/)**
Información de referencia detallada sobre herramientas integradas, opciones de alojamiento y especificaciones técnicas para ayudar a las organizaciones comunitarias a tomar decisiones informadas sobre la implementación.

### 🎓 **[Guías](./guides/)**
Guías completas para establecer prácticas de datos centradas en la comunidad, incluyendo protocolos de soberanía de datos indígenas y flujos de trabajo específicos de herramientas.

## Primeros pasos

Usa la barra de navegación superior para explorar cada sección de este sitio de documentación:

1. **Empieza con la [Visión general](./overview/)** para comprender el propósito y los principios de diseño de Guardian Connector.
2. **Revisa la [Referencia](./reference/)** para aprender sobre herramientas integradas y opciones de implementación.  
3. **Sigue las [Guías y Tutoriales](./guides/)** para un aprendizaje práctico y el desarrollo de habilidades.

## Perfiles de usuario

No todos usan todas las capas de Guardian Connector. Diferentes [perfiles de usuario](./overview/user-personas/) suelen operar diferentes partes de la pila. Por ejemplo:

- Un [Usuario Técnico Indígena](./overview/user-personas/#itu-1) de cualquier nivel de experiencia solo puede usar las aplicaciones de recopilación de datos que alimentan Guardian Connector.
- Un [Usuario Técnico Indígena avanzado](./overview/user-personas/#itu-3) también puede manejar algunas configuraciones básicas de vistas o paneles.
- Un [Tomador de Decisiones Indígena](./overview/user-personas/#idm) solo puede acceder a paneles y vistas de datos, y no necesitará saber mucho más sobre los detalles técnicos del sistema.
- Un [Usuario Avanzado Organizacional](./overview/user-personas/#opu) puede administrar toda la pila, a veces con el apoyo de un [Socio de Soporte Técnico](./overview/user-personas/#tsp), y en otros casos completamente por su cuenta.
