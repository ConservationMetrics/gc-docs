# Sobre Guardian Connector

_Guardian Connector es una plataforma de integración y monitoreo de datos segura de código abierto._

Posiciona a los Pueblos Indígenas para recopilar, gestionar y poseer datos sobre sus territorios según sus propios términos. Agiliza el camino de la recopilación de datos a la acción, ayudando a los usuarios a crear potentes herramientas de defensa que apoyen la protección de sus tierras y aguas.

:::tip Visita el sitio web de Guardian Connector
:link: Para una introducción general a la plataforma, visita el [sitio web de Guardian Connector](https://guardianconnector.net).
:::
